Cập nhật dữ liệu
Chọn file Excel báo cáo J1 PA (…MIRROR/NORMAL :số máy) (.xlsm, .xlsx, .xls, .xlsb, .csv, .txt — tự nhận MIRROR / NORMAL từ tên file hoặc ô tiêu đề; máy lấy từ partnb / tên file / tiêu đề). Dữ liệu được lưu trên thiết bị này; mỗi máy tính cần tự kết nối thư mục chung một lần. Dữ liệu cập nhật bằng nút tải file không tự đồng bộ sang máy khác.
File .txt từ CMM (không có ngày/ca):
Tên máy tự nhận từ cột partnb / tên file / ô tên máy và khớp với máy đã có; đuôi L1, L2 được bỏ; đuôi ST, CT được đưa vào mục Ca (phần Mở rộng). Phân loại Mirror / Normal theo thứ tự: ô Mã hàng (nếu chọn) → tên thư mục chứa file (thư mục hoặc thư mục con có chữ Mirror / Normal, kể cả thư mục gốc đã kết nối) → tên file / planid → máy đã thuộc mã hàng → mã đang xem.
Ảnh JPG/PNG — mỗi mã hàng (Mirror/Normal) một bản vẽ, đang chọn mã nào thì lưu cho mã đó
